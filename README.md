# Audio Tab Finder

A Chrome extension to instantly find, mute, and close tabs playing audio.

## Features

- **Find audio tabs** - See all tabs currently playing sound in one place
- **Quick navigation** - Click to jump to any tab instantly
- **Mute/unmute** - Toggle audio without leaving your current tab
- **Close tabs** - Close noisy tabs directly from the popup
- **Badge counter** - See how many tabs are playing audio on the extension icon

## Installation

### Chrome Web Store

[Install from Chrome Web Store](https://chromewebstore.google.com/detail/audio-tab-finder-%E2%80%93-find-m/ecnkofmcbijompohhddkaaekdaenhmhh)

### Manual Installation

1. Download or clone this repository
2. Open `chrome://extensions/` in Chrome
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extension folder

## Permissions

This extension only requires the `tabs` permission to:
- Detect which tabs are playing audio
- Display tab titles and URLs
- Switch between tabs
- Mute/unmute and close tabs

## Privacy

Audio Tab Finder does not collect, store, or transmit any user data. Everything runs locally on your device.

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `↑` `↓` | Navigate between tabs |
| `Enter` / `Space` | Switch to selected tab |
| `M` | Mute/unmute selected tab |
| `Delete` | Close selected tab |
